# Aula Virtual - Ruleta Dinámica y Sorteo de Equipos

Proyecto colaborativo desarrollado en **HTML5, CSS3 y Vanilla JavaScript** que simula herramientas interactivas para el aula virtual.

## 🚀 Funcionalidades

1. **Ruleta Dinámica:**
   - Renderizado interactivo en Canvas HTML5.
   - Opciones dinámicas editables.
   - Atajos de teclado (`SPACE`, `S`, `R`, `E`, `F`).
2. **Sorteo de Equipos:**
   - Agrupamiento aleatorio por número de equipos o participantes por equipo.
   - Reconocimiento de líderes de grupo marcados con `*`.
   - Exportación y gestión de resultados.

## 🛠️ Tecnologías Utilizadas

- HTML5 / CSS3 (Flexbox y Grid)
- JavaScript Vanilla (Canvas API)
- Git & GitHub (Estrategia de ramas por integrante)
